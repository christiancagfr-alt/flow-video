# v0.9.49 MATERIAL Request Hard Gate

这版针对“素材模式偶发漏图，实际发成纯文生视频”做 fail-closed 修复。

- **最终请求硬门**：MATERIAL / VIDEO_REFERENCES 模式在真正的 Flow fetch/XHR 生成请求发出前，再检查一次该请求负载是否包含当前任务图片的精确素材 identity。没有素材 identity 时，请求会在本地被阻止，绝不会发给 Flow。
- **无法验证也禁止提交**：如果 Flow 改变请求封装导致请求体无法读取，MATERIAL 任务按保守策略阻止，而不是降级为文生视频。
- **自动重新挂图**：素材未绑定、提示词写入导致素材丢失、提交瞬间请求中缺图等安全错误，都进入同一可重试链路，重新 clear → 切模式/模型 → 选择当前图片 → 写提示词 → 稳定校验 → 再尝试提交。
- **精确当前任务素材**：请求门校验的是当前任务图片的 ID/别名，不接受页面其他历史图片、上一任务残留素材或“页面里有图片”作为通过条件。
- **FRAME 不受影响**：帧模式仍按原 firstFrame 路径运行；下载、调度、跨波次间隔、提交确认逻辑保持不变。

原则：素材模式 **有当前任务素材才允许请求离开浏览器；没有素材就等待/重试/报错，永不自动降级为纯文本生成。**
