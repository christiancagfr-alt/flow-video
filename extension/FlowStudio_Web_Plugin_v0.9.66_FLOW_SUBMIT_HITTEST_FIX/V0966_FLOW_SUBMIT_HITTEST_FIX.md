# v0.9.66 Flow 提交按钮命中检测修复

问题：Flow Studio 面板默认打开，使用固定定位和极高 z-index；在常见屏幕宽度下会覆盖 Flow 底部的“开始生成”按钮。原生 CDP 点击仍会返回成功，但实际命中插件面板，Flow 没有发起生成请求，随后出现“Flow 页面恢复中 2/5”。

修复：

- 原生点击前用 `document.elementFromPoint()` 检查真实命中对象。
- 若命中插件自身面板，仅在点击期间把插件根节点设为 `pointer-events:none`。
- 再次命中检测，确认底层对象确实属于 Flow Generate 按钮后才发送一次 CDP 点击。
- 点击完成、失败或超时都会恢复插件面板交互。
- 点击前增加 90ms 布局稳定等待，并输出 `overlayBypassed` / `hit` 诊断。
- 将笼统的“Flow 页面恢复中”改为实际原因提示，例如“Flow 未接收到生成点击”或“生成按钮已刷新或暂不可点击”。
- 统一 manifest、面板、后台与下载诊断版本号为 0.9.66，便于确认浏览器没有继续运行旧代码。

未修改：任务调度、上传、下载、素材绑定、帧模式、生成间隔和防重复提交核心逻辑。
