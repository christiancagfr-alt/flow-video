# 网页插件 v0.9.62 修复说明

## 日志结论
本次检查 FlowStudio-download-diagnostics (1).json（导出时间 2026-09-21 07:27:32 UTC）。

- 任务 4052 在 07:25:55 记录上传验证通过；07:25:56 开始准备；07:25:57 同一批再次自动启动；07:26:01 已报参考图片未检测到。素材目录确认和生成框确认是两个阶段，旧代码只对后者短暂重试便判失败。
- 日志记录多次相同命令重复自动启动。上传确认在批次互斥锁之前，多个后台唤醒可同时进入，干扰图片选择和任务计数。
- 后台保护原先仅处理已冻结标签，并立即断开调试连接；未被冻结但被限速的后台页面缺少持续保护。
- 日志也有独立的真实视频生成失败，不能将所有失败都归因于图片上传。日志不能单独证明图片文件传输是否已经完成。

## 本次修改
1. 上传确认前取得批次互斥锁，等待后核对命令身份，避免重复启动和过期批次继续执行。
2. 对明确发生在点击生成之前的图片、参考帧、按钮未就绪，增加最多 36 次、每次 5 秒的等待；实际执行检查另计耗时。界面明确显示“等待图片处理和生成框就绪 · 尚未点击生成”。不是取消图片校验，也不是把失败伪装成成功。达到上限仍会报错，避免无限卡死。
3. 后台工作标签持续保持同一调试会话，上传拖拽、回车和后台维护串行共享会话，避免彼此断开。工作结束恢复原自动丢弃设置。自动维护不切换标签、不抢窗口焦点。
4. 继续保留上传完整性检查、失败文件名历史、下载去重及不确定提交的恢复流程。已经可能点击生成的超时不会走新增的图片等待重提逻辑。
5. 保留文案长度不阻止提交的要求；视频参数本身仍必须合法。
